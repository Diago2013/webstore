开发者中心

将你的作品发布到 WebStore

分享你的 Web 工具与网站，触及全球用户

欢迎来到 WebStore 开发者中心。在这里，你可以将自己的 Web 工具、网站和应用上传到平台，与全球用户分享你的创意。

上传你的作品

简单几步，让你的作品被世界看到

📦

1. 准备作品

确保你的 Web 工具或网站可以通过 URL 公开访问，支持 HTTP/HTTPS 协议。建议提供清晰的截图和描述。

✍️

2. 填写信息

提交工具名称、分类、描述、标签、截图和访问链接。描述越详细，越容易被用户发现和使用。

✅

3. 审核发布

提交后自动通过安全检测，人工审核通过后即刻上线。审核周期通常为 1-3 个工作日。

📊

4. 持续运营

通过数据仪表盘查看使用数据，响应用户反馈，更新版本，参与社区互动，持续优化你的作品。

常见问题

关于上传作品的常见疑问解答

我的网站需要开源吗？

不需要。WebStore 支持 闭源商业工具、开源项目 和 免费工具。你保留所有知识产权。

审核需要多长时间？

标准审核周期为 1-3 个工作日。优质作品可申请加急审核（24 小时内）。

如何更新已发布的工具？

在开发者仪表盘中找到你的工具，点击「更新版本」，上传新版本信息后重新提交审核即可。

可以上传多少个作品？

标准版开发者最多上传 5 个作品，专业版无限量。

如何获取用户反馈？

所有用户对你的工具的评价、Bug 报告和功能建议都会在开发者仪表盘的「用户反馈」面板中统一展示。

出现违规如何申诉？

如对审核结果有异议，可通过开发者中心内的「申诉通道」提交申诉，平台将在 3 个工作日内复核。

开发者支持

如果你在上传过程中遇到任何问题，可以联系开发者支持团队。我们提供 7x24 小时的技术支持服务。
